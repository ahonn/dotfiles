# Animation Review Reference Index

Shared web motion guidance lives in `emil-design-eng`. This index preserves the
existing reference path without maintaining a second conflicting rule catalog.
Read only the relevant topic.

| Review question | Reference |
| --- | --- |
| Purpose, frequency, easing, duration, springs, scale, or stagger | [Motion decisions](../emil-design-eng/references/motion-decisions.md) |
| Buttons, tooltips, overlays, entry/exit, toasts, clipping, or hold feedback | [Web component patterns](../emil-design-eng/references/web-components.md) |
| Rendering cost, reduced motion, input modes, or how to verify a concern | [Performance and accessibility](../emil-design-eng/references/performance-accessibility.md) |

The examples are contextual tuning guidance. Review findings must connect the
implementation to a concrete user impact; differing from a sample value is not a
defect. Library execution paths and API details depend on the installed version.

For React Native or native code, use the target platform's APIs and performance
evidence. A CSS recommendation is not a rule for a native animation driver.
